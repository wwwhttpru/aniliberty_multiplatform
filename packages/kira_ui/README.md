# kira_ui

KIRA design system for AniLibria — a dark cyberpunk-anime visual language.

Pure presentation package: design tokens (color, type, sizing, effects) and the
widget library (atoms → molecules → organisms). It must **not** depend on app
layers (features, data sources, DI, networking, storage) — components take
primitives / view-models, mapping lives in the app.

Designed in Figma (file `PsoEqySHZnxPvkviH0YZw7`). Browse the components in
[`kira_gallery`](../kira_gallery) (Widgetbook).
